# Screenshots

**This repository does not include screenshots of a running application**, because the repository contains specifications, schemas, templates and scripts, and no deployed app. Do not add mock-ups and present them as screenshots.

## What you can capture honestly today

1. **Email template previews.** Run `npm run preview` (or `node scripts/build-email-preview.js <template.html>`), open `dist/email-preview-<template>.html` in a browser and capture the desktop and mobile tabs.
2. **Validation output.** Capture the terminal after `npm run validate`.

## What to add after you build the Base44 app

Add real captures of your own deployment with these names, then link them from the root `README.md`:

| File | Content |
|------|---------|
| `pipeline-dashboard.png` | Ranked opportunity pipeline |
| `score-card.png` | Score breakdown for one opportunity |
| `email-studio-desktop.png` | Rendered desktop preview |
| `email-studio-mobile.png` | Rendered mobile preview |
| `approval-queue.png` | Pending approvals |

Remove any real recipient addresses, personal data and organisational documents before committing images.
